# Social Media Sentiment Analysis

## Project Overview
Analyzed social media reviews and climate-related tweets to identify public sentiment using Natural Language Processing (NLP).

## Tools & Technologies
- Python, Pandas, NumPy
- NLTK (VADER Sentiment Analysis)
- Matplotlib, Seaborn
- SciPy, WordCloud
- Jupyter Notebook

## Methodology
1. Cleaned and preprocessed text data.
2. Applied VADER to classify sentiment as Positive, Negative, or Neutral.
3. Analyzed sentiment patterns by platform, topic, and time.
4. Visualized results and generated insights.

## Key Findings
- Instagram: 46.8% positive sentiment.
- Twitter: 49.8% negative sentiment.
- Platform sentiment differences were statistically significant.
- Engagement metrics showed little variation across sentiment groups.

## Business Value
The analysis demonstrates how sentiment analysis can help identify customer concerns, understand public opinion, and support data-driven decisions.

## Limitations
The datasets contain repeated text templates, so findings demonstrate the analysis methodology and may not represent real-world sentiment.

## How to Run
Install the required libraries and run `sentiment_analysis.py` or open `Sentiment_Analysis_Project.ipynb` in Jupyter Notebook.
